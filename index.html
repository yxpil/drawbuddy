步骤 → 流程图

每行写一个步骤，自动生成纵向流程图。行首用 # 表示判断（菱形），其后用两个空格缩进的行表示该判断的分支。

大纲 → 思维导图

第一行为中心主题，之后按缩进（2 空格 / Tab）表示层级。

主题形状可选：圆角 / 方形 / 圆形 / 云朵

时间 → 时间线

每行格式：时间 : 事件1 : 事件2（用英文冒号分隔）。

角色 → 时序图

每行格式：甲 ->> 乙 : 消息，也支持虚线箭头；首行可用 participant 名称 声明角色。

数据 → 统计饼图

每行格式：名称 : 数值。
